## Contributions and redistribution

New contributions use the licenses above and a [DCO sign-off](https://github.com/kanivet-ai/kanivet-oss/blob/main/CONTRIBUTING.md#commit-sign-off-and-licensing). A sign-off records the contributor's certification; it does not transfer copyright or replace a missing license grant.

When distributing source or packaged applications, include applicable license texts and copyright/attribution notices. Preserve upstream NOTICE content where required. The [NOTICE](NOTICE) file covers project attribution; it is not a complete dependency notice inventory.

See [DEPENDENCIES.md](https://github.com/kanivet-ai/kanivet-oss/blob/main/docs/DEPENDENCIES.md) for the dependency review procedure. Check each component's license and notices when redistributing the application.
